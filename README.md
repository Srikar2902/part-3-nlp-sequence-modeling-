# Part 3: NLP and Sequence Modeling

## Project Overview
This project explores Natural Language Processing (NLP) by classifying customer support messages into Positive, Neutral, or Negative sentiments. 

## Key Features
- **Preprocessing:** Cleaning text by removing special characters and stopwords.
- **Vectorization:** Comparing traditional TF-IDF methods with modern Sequence-based Tokenization.
- **Modeling:** - Baseline: Logistic Regression.
  - Advanced: Long Short-Term Memory (LSTM) network to capture word order.

## Folder Structure
- `notebook.ipynb`: Full code and analysis.
- `requirements.txt`: Necessary Python libraries.
- `results/`: Contains evaluation metrics and prediction samples.
